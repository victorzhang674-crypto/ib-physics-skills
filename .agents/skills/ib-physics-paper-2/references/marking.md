# Paper 2 marking

Sources include the IB *Physics guide* (updated November 2024), printed pp. 62–65, 76–77 and 80, and the [IB specimen papers and markschemes](https://ibo.org/globalassets/new-structure/programmes/dp/pdfs/physics-hl-sl-specimen-papers-1a-2b-2-en.pdf). The guide's May 2023 correction changed the SL maximum to 50. The linked SL specimen has a 50-mark question paper and a legacy 55-mark line in the marking notes. Reconcile the printed subparts with the matching marking rows for the specific version.

## Award marks by subpart

1. Read the question, command term and printed maximum together with the corresponding answers and notes. Separate independent credit from steps that depend on prior working. Check acceptable alternatives, required elements, allowed ranges and any cap.
2. Map each point to the student's equation, reasoning, diagram or result. Accept physically equivalent reasoning when the scheme allows it, and use one valid alternative path without adding points across alternatives. For an answer alone, check whether the scheme requires working, particularly for a show or derive task.
3. When the notes allow error carried forward (ECF), mark the originating error and re-evaluate the later steps using the student's intermediate value. Award follow-through only for valid downstream work. Apply the scheme's directions on rounding, units and significant figures. Give presentation advice separately when the issue does not cost a mark under the scheme.
4. Report `subpart | earned/available | credited evidence | missing point or correction`. Count confirmed blanks in a complete script as zero. List missing or illegible material as pending and give an assessable subtotal. For provisional marking, show the reasoning and flag decisions that depend on the official notes. Convert raw marks to grades only with the relevant boundaries and enough component information for the requested grade.

## Match the response to the command

| Command | Evidence to look for |
| --- | --- |
| State / identify | The specific quantity, direction, feature or choice requested |
| Calculate / determine | A sound route to the required value, including relevant working |
| Show | A chain of steps reaching the stated result |
| Describe | The requested features or changes, with sufficient detail |
| Explain | The principle and a causal link from the given conditions to the outcome |
| Deduce | The inference and the information that supports it |
| Suggest / discuss | A plausible proposal, or a balanced evidence-based consideration for discuss |
| Draw / sketch | Required features and labels, with accurate scale or plotting where draw calls for it |

For a multistep answer, pinpoint where the model or reasoning first diverges. For example, if a student uses the total energy of a system when asked for the change in one object's kinetic energy, show how the choice of system changes the calculation and check any later dependent parts under the scheme.
