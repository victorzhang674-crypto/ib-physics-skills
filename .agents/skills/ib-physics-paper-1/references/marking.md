# Paper 1 marking

Sources include the IB *Physics guide* (updated November 2024), printed pp. 28–32, 62–65 and 76–77, and the [IB specimen papers and markschemes](https://ibo.org/globalassets/new-structure/programmes/dp/pdfs/physics-hl-sl-specimen-papers-1a-2b-2-en.pdf). Use the matching paper's marking notes for the actual award.

## Paper 1A

- Align each response by question number before comparing with the key. One mark for a correct choice. An incorrect or confirmed blank choice earns zero, with no deduction. Flag unreadable or ambiguous responses separately from blanks and follow the paper's instructions on multiple marks or corrections.
- With a verified key, score selections even if reasoning is absent. To explain misses, use the question and its options. If the key is absent, independently solve the supplied items and flag any ambiguous question or missing diagram. A list of choices by itself cannot establish accuracy.
- Report the total and the missed question numbers. For each useful diagnosis, show the selected and correct options, the decisive reasoning and a short drill. Distinguish an inferred misconception from one supported by the student's working.

## Paper 1B

- Inspect the full figure, legend, units, multipliers and answer, including handwritten graphs. Flag a cropped graph or unreadable scale when it prevents a reliable read-off.
- Match observable evidence to each subpart's marking points. Read the notes for required combinations, alternatives, dependencies, acceptable ranges and mark caps. Give equivalent answers their due and keep different alternative solution paths separate. Apply error carried forward (ECF) according to the scheme. Identify the initial loss and assess later working using the student's carried value when allowed. Follow the scheme for units, significant figures and tolerances.
- Diagnose the specific skill. Check intervals and scale factors for read-offs, well-separated points on the fitted line for gradients, and gradient units from both axes. For a claimed relationship, check the intercept and error bars where relevant. Use the requested convention for uncertainties, including extreme acceptable gradients when asked. For experimental design, link each control, range, repeat or instrument choice to its effect on the result.
- Report `subpart | earned/available | evidence | change to recover the mark`. Show 1A and 1B subtotals before the combined mark when both are assessed. Count a confirmed blank in a complete script as zero. If a page was omitted from the upload, report the assessable subtotal and list the pending items.

## Original data question calibration

For a two-mark question asking for the gradient of a plotted linear fit, an original scheme might give one mark for two suitably separated read-offs on the line and one for the correct change in y divided by change in x. Set the acceptable range using the actual scale and plot. An official question may allocate these marks differently.
